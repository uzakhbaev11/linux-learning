# Модуль 11. Задания

```bash
lab setup 11
```

Сюжет: тебе выдали доступ к серверу: пользователь `deploy`, пароль `deploy`.
Задача — настроить вход по ключу, выкатить релиз и закрыть вход по паролю.

«Сервер» здесь — этот же Linux (`localhost`). В жизни на месте `localhost` будет IP сервера.

---

## Задание 1. Ключ

1. Создай ключ типа **ed25519**: `ssh-keygen -t ed25519`. Файл по умолчанию, passphrase можно оставить пустой.
2. Посмотри, что появилось: `ls -la ~/.ssh`.
3. Проверь права: `~/.ssh` — `700`, приватный ключ — `600`. Если не так, исправь через `chmod`.
4. Выведи **публичный** ключ: `cat ~/.ssh/id_ed25519.pub`. Именно его можно отдавать.

## Задание 2. Вход по ключу

1. Сначала войди по паролю: `ssh deploy@localhost`. На вопрос о fingerprint ответь `yes`, пароль `deploy`.
   Осмотрись (`whoami`, `pwd`) и выйди: `exit`.
2. Скопируй свой ключ на сервер: `ssh-copy-id deploy@localhost`.
3. Снова `ssh deploy@localhost`. Пароль больше не спрашивают? 🎉 Выйди.

## Задание 3. Короткое имя

Создай `~/.ssh/config`, чтобы `ssh server` входил на `localhost` как `deploy`.
Формат есть в теории. После этого должно работать просто:
```bash
ssh server
```

## Задание 4. Команды на сервере

Не заходя на сервер интерактивно:
1. Узнай, под каким пользователем ты там работаешь (`whoami`), и сохрани ответ **у себя** в `~/m11/remote_user.txt`.
2. Сохрани место на диске сервера (`df -h`) в `~/m11/remote_disk.txt`.

## Задание 5. Выкатываем релиз

1. Скопируй `~/m11/release.txt` на сервер в домашнюю папку `deploy` через `scp`.
2. Убедись, что файл там: `ssh server 'cat release.txt'`.

## Задание 6. Закрываем сервер

Делай это **только после того**, как `ssh server` пускает без пароля.

1. Открой `sudo nano /etc/ssh/sshd_config` (пароль sudo: `student`).
2. Найди строки `PasswordAuthentication` и `PermitRootLogin` (поиск в nano: `Ctrl+W`).
   Убери `#` в начале и поставь обоим значение `no`.
3. Перезапусти SSH-сервер: `sudo rc-service sshd restart`.
4. Проверь, что ключ работает: `ssh server`.
5. Проверь, что пароль больше не принимается:
   `ssh -o PubkeyAuthentication=no deploy@localhost` должен ответить `Permission denied`.

# Модуль 4. Задания

```bash
lab setup 4
```

В `~/m04` появятся: лог веб-сервера `access.log`, скрипт `deploy.sh` и журнал деплоев `history.log`.

Сюжет: ночью API тормозил. Тимлид просит разобраться, кто и как нагружал сервер.
Всё решается **цепочками команд**, без ручного подсчёта.

Посмотри на лог: `head -5 ~/m04/access.log`. Каждая строка — один запрос:
```
IP  -  -  [дата  зона]  "МЕТОД  ПУТЬ  ПРОТОКОЛ"  СТАТУС  БАЙТЫ
$1         $4    $5     $6      $7    $8         $9      $10
```

---

## Задание 1. Считаем запросы

1. Запиши **только число** строк лога в `~/m04/total.txt`.
   💡 `wc -l access.log` печатает ещё и имя файла. Как отдать файл через stdin (`<`), чтобы осталось одно число?
2. Посчитай, сколько запросов закончились статусом `404`, и запиши **только число** в `~/m04/count_404.txt`.
   💡 Найди строки (`grep` или `awk '$9 == 404'`), затем передай их по пайпу в `wc -l`.

## Задание 2. Кто нас долбит?

Сохрани в `~/m04/top_ips.txt` **три самых активных IP** в формате `uniq -c`
(количество и IP, от большего к меньшему):
```
    150 203.0.113.7
    ...
```
Собирай цепочку по шагам: вырезать IP → отсортировать → посчитать повторы → отсортировать по числу → взять 3.

## Задание 3. Какие адреса вообще запрашивали

1. Сохрани в `~/m04/paths.txt` список **уникальных путей** (7-е поле), отсортированный по алфавиту.
   Каждый путь только один раз.
2. Сохрани в `~/m04/methods.txt` уникальные HTTP-методы **без кавычек** (`GET`, `POST`).
   💡 В 6-м поле метод стоит вместе с кавычкой: `"GET`. Кавычку уберёт `tr -d '"'`.

## Задание 4. Разделяем вывод и ошибки

Скрипт `deploy.sh` печатает обычные шаги в stdout, а предупреждения и ошибки в stderr.

1. Запусти его так, чтобы обычный вывод попал в `~/m04/deploy.out`, а ошибки в `~/m04/deploy.err`.
   На экране не должно появиться ничего.
2. Запусти его ещё раз так, чтобы **оба потока** попали в один файл `~/m04/all.log`.
3. Запусти так, чтобы на экран вывелись только шаги, а ошибки исчезли.

## Задание 5. Дописать, а не затереть

В `~/m04/history.log` журнал деплоев. Добавь **в конец** строку:
```
2026-11-27 deploy v1.3 done
```
Три старые строки должны остаться на месте! Если случайно затёр, восстанови через `lab setup 4`.

## Задание 6. tee

Одной цепочкой сохрани все строки со статусом `500` в `~/m04/errors500.txt`
и **одновременно** выведи на экран их количество.

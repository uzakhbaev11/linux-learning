## Задание 1. greet.sh — аргументы и коды возврата

Скрипт принимает имя и здоровается:

```
$ ./greet.sh Анна
Привет, Анна!
$ ./greet.sh
Использование: greet.sh ИМЯ
$ echo $?
1
```

- Есть аргумент: печатает ровно `Привет, ИМЯ!` и завершается с кодом 0.
- Нет аргумента: печатает подсказку (лучше в stderr, через `>&2`) и завершается с кодом **1**.

💡 Сколько аргументов передали, хранится в `$#`.

## Задание 2. log_summary.sh — считаем уровни логов

Скрипт получает путь к логу и печатает, сколько там строк каждого уровня, ровно в таком формате:

```
$ ./log_summary.sh app.log
INFO: 121
WARN: 24
ERROR: 9
```

- Используй цикл `for` по уровням `INFO WARN ERROR` и `grep -c`.
- Если файла нет: напечатать `Файл не найден: ПУТЬ` и выйти с кодом **2**.
- Скрипт должен работать с **любым** логом, а не только с `app.log`: проверка подсунет свой файл.

## Задание 3. healthcheck.sh — проверка сервера перед деплоем

Скрипт получает файл со списком путей и проверяет каждый (читай файл построчно через `while read`):

```
$ ./healthcheck.sh checklist.txt
OK /etc/passwd
OK /etc/hosts
OK /var/log
MISSING /etc/myapp/config.yml
OK /home/student
MISSING /srv/myapp/.env
Проблем: 2
```

- Путь существует (файл или папка): `OK путь`, иначе `MISSING путь`.
- В конце строка `Проблем: N`.
- Код возврата: **0**, если всё на месте, и **1**, если есть хоть одна проблема.
  Тогда твой скрипт можно поставить перед деплоем: `./healthcheck.sh list.txt && ./deploy.sh`.
- Вынеси проверку одного пути в **функцию** `check_path`.

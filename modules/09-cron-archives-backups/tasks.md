# Модуль 9. Задания

```bash
lab setup 9
```

В `~/m09` появятся проект `myapp` (вместе с тяжёлой папкой `node_modules`) и старый лог `old.log`.

Сюжет: на проекте нет ни одного бэкапа. Ты настраиваешь резервное копирование так,
чтобы оно работало само, каждую минуту, и не забивало диск.

---

## Задание 1. Первый архив

1. Посмотри, что внутри проекта: `tree ~/m09/myapp`.
2. Создай архив `~/m09/myapp.tar.gz` с папкой `myapp`, но **без** `node_modules`
   (её всегда можно восстановить через `npm install`, хранить в бэкапе незачем).
   Внутри архива пути должны начинаться с `myapp/`, а не с `/home/...`. Подсказка: флаг `-C`.
3. Сохрани список файлов архива в `~/m09/contents.txt`.

## Задание 2. Восстановление

Бэкап, который не проверяли, не считается бэкапом.

1. Создай папку `~/m09/restore`.
2. Распакуй туда архив (не переходя в неё через `cd`).
3. Сравни: `diff ~/m09/myapp/config/settings.ini ~/m09/restore/myapp/config/settings.ini`.
   Пусто? Значит, восстановилось.

## Задание 3. Сжимаем старый лог

1. Посмотри размер `~/m09/old.log` (`ls -lh`).
2. Сожми его через `gzip` так, чтобы остался только `old.log.gz`. Во сколько раз уменьшился размер?
3. **Не распаковывая** архив, посчитай строки с `ERROR` и запиши число в `~/m09/old_errors.txt`.

## Задание 4. Скрипт бэкапа

Напиши `~/m09/backup.sh`, который:

1. создаёт папку `~/m09/backups`, если её нет (`mkdir -p`);
2. упаковывает `myapp` без `node_modules` в `~/m09/backups/myapp_ДАТА.tar.gz`, где ДАТА — `$(date +%F_%H-%M-%S)`;
3. удаляет старые бэкапы, оставляя **3 самых свежих**;
4. печатает `Бэкап создан: ИМЯ_ФАЙЛА`.

💡 Внутри скрипта используй полные пути (`$HOME/m09/...`): cron запустит его не из твоей папки.
Сделай скрипт исполняемым и запусти руками несколько раз. Сколько архивов в `backups`?

## Задание 5. По расписанию

1. Через `crontab -e` добавь задание: запускать `backup.sh` **каждую минуту**,
   а весь вывод (и ошибки тоже) дописывать в `~/m09/backup.log`. Пиши полные пути.
2. Посмотри своё расписание: `crontab -l`.
3. Подожди 2–3 минуты и проверь `cat ~/m09/backup.log` и `ls -l ~/m09/backups`.
   Новые бэкапы появляются, а старых всё равно не больше трёх? Значит, работает.

> В браузере cron работает, пока открыта вкладка с сайтом. На настоящем сервере он работает всегда.

Когда закончишь с проверкой, расписание можно удалить: `crontab -r`. Но сначала запусти `lab check 9`.

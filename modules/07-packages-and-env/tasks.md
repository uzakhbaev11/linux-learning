# Модуль 7. Задания

```bash
lab setup 7
```

В `~/m07` появятся конфиг приложения `config.json` и «приложение» `start.sh`, которое берёт
настройки из переменных окружения.

Сюжет: тебе дали чистый сервер. Нужно поставить утилиту, настроить своё окружение и запустить
приложение с секретами из `.env`.

---

## Задание 1. Где живут команды

1. Узнай, где лежат команды `ls`, `bash` и `htop` (`command -v`).
2. Посмотри, что такое `cd` и `ls` с точки зрения bash (`type`). Чем они отличаются?
3. Выведи свой `PATH`. В каких папках shell ищет программы?
4. Узнай, какой **пакет** установил файл `/usr/bin/htop`, и сохрани вывод команды в `~/m07/owner.txt`.

## Задание 2. Ставим пакет

Нужно достать поля из JSON. Для этого есть утилита `jq`, но её ещё нет:

```bash
jq --version        # command not found
```

1. Обнови список пакетов и установи `jq` (пароль для `sudo`: `student`).
2. Посмотри конфиг красиво: `jq . ~/m07/config.json`
3. Сохрани **версию** приложения (только `2.4.1`, без кавычек) в `~/m07/version.txt`.
   💡 Поле достают так: `jq -r .имя_поля файл`. Флаг `-r` убирает кавычки.
4. Сохрани **порт базы данных** в `~/m07/db_port.txt`. Подумай, как достать вложенное поле.

## Задание 3. Свои команды из `~/bin`

1. Создай папку `~/bin` и в ней скрипт `hello` (без `.sh`), который печатает `Hello from bin`:
   ```bash
   #!/usr/bin/env bash
   echo "Hello from bin"
   ```
2. Сделай его исполняемым.
3. Добавь `~/bin` в `PATH` **навсегда**, через `~/.bashrc`.
4. Перечитай `~/.bashrc` и проверь, что из любой папки работает просто `hello`.

## Задание 4. Alias

Добавь в `~/.bashrc` сокращение `ll`, которое выполняет `ls -la`. Перечитай файл и проверь: `ll ~`.

## Задание 5. Секреты в `.env`

1. Попробуй запустить приложение: `cd ~/m07 && ./start.sh`. Оно ругается: нет настроек.
2. Создай файл `~/m07/.env` с двумя переменными:
   - `APP_PORT=3000`
   - `DB_PASSWORD=` любой пароль
3. Закрой `.env` от чужих глаз: читать и писать может **только владелец**.
4. Загрузи переменные из `.env` в текущий shell так, чтобы их увидел скрипт, и запусти `./start.sh`.
5. Эксперимент: запусти `APP_PORT=8080 ./start.sh`. На каком порту запустилось? Почему?

## Что такое Linux и зачем он бэкендеру

**Linux** — это ядро операционной системы. Ядро управляет железом: процессором, памятью, дисками и сетью.
**Дистрибутив** — это ядро плюс программы вокруг него: Ubuntu, Debian, CentOS, Alpine и другие.

Почему без Linux никуда:
- **Почти все серверы работают на Linux.** Твой бэкенд в продакшене почти наверняка будет крутиться на нём.
- **Docker-контейнеры — это Linux.** Даже на Mac Docker запускает внутри Linux.
- **CI/CD** (GitHub Actions, GitLab CI) выполняет сборки на Linux-машинах.
- На сервере **нет графического интерфейса**: только терминал. Кто умеет в нём работать, тот может сам задеплоить, найти баг в логах и поднять упавший сервис.

## Терминал и shell

- **Терминал** — окно, в которое ты вводишь текст.
- **Shell (оболочка)** — программа, которая понимает твои команды и выполняет их. Самая распространённая — **bash**. Её мы и используем.

Когда ты заходишь в учебный Linux, ты видишь **приглашение (prompt)**:

```
student@linux-lab:~$
│       │         ││
│       │         │└─ $ — обычный пользователь (# — значит ты root, суперпользователь)
│       │         └── ~ — текущая папка (~ = твоя домашняя папка)
│       └──────────── имя компьютера (hostname)
└──────────────────── имя пользователя
```

## Устройство команды

```
ls   -l -a   /etc
│    │       │
│    │       └─ аргумент: С ЧЕМ работать
│    └───────── опции (флаги): КАК работать
└────────────── команда: ЧТО делать
```

- Короткие флаги можно склеивать: `ls -l -a` = `ls -la`
- У флагов бывает длинная форма: `ls --all` = `ls -a`
- **Регистр важен!** `ls -s` и `ls -S` — разные флаги. `File.txt` и `file.txt` — разные файлы.

## Где я? Кто я?

| Команда    | Что делает                                    |
|------------|-----------------------------------------------|
| `pwd`      | показывает текущую папку (print working directory) |
| `whoami`   | имя текущего пользователя                     |
| `hostname` | имя компьютера                                |
| `date`     | дата и время                                  |
| `uname -a` | информация о системе и ядре                   |
| `clear`    | очистить экран (или `Ctrl+L`)                 |

## Смотрим содержимое: `ls`

```bash
ls              # что в текущей папке
ls /etc         # что в папке /etc
ls -l           # подробно: права, владелец, размер, дата
ls -a           # показать скрытые файлы (их имена начинаются с точки)
ls -la          # подробно и вместе со скрытыми
ls -lh          # размеры в понятном виде (K, M, G)
ls -lt          # сортировка по времени изменения
```

**Скрытые файлы.** В Linux файл скрыт, если его имя начинается с точки: `.bashrc`, `.git`, `.env`.
Для бэкендера это важно: файлы `.env` с секретами тоже скрытые.

## Перемещаемся: `cd`

```bash
cd /etc         # перейти в /etc
cd ..           # подняться на уровень выше
cd ~            # домой (/home/student)
cd              # тоже домой
cd -            # вернуться в предыдущую папку
cd ../..        # на два уровня вверх
```

Специальные обозначения:
- `~` — домашняя папка
- `.` — текущая папка
- `..` — родительская папка
- `/` — корень, самая верхняя папка системы

## Читаем файл: `cat`

```bash
cat file.txt    # вывести содержимое файла на экран
```

Подробнее о работе с текстом поговорим в модуле 3.

## Сохраняем вывод в файл: `>`

Пока запомни просто: символ `>` записывает результат команды в файл, а не на экран.

```bash
whoami > me.txt     # результат whoami попадёт в файл me.txt
cat me.txt          # проверим: student
```

⚠️ Если файл уже существует, `>` **перезапишет** его. Подробно разберём в модуле 4.

## Как получить помощь

Никто не помнит все флаги наизусть. Главный навык — **уметь найти ответ самому**.

```bash
man ls          # полное руководство по команде (manual)
ls --help       # краткая справка
type cd         # что это за команда: встроенная в shell или отдельная программа
```

Управление внутри `man`:
- `↑ ↓` или `j k` — прокрутка
- `Пробел` — страница вниз
- `/слово` — поиск, `n` — следующее совпадение
- `q` — выход

## Горячие клавиши (сэкономят тебе часы)

| Клавиши     | Что делает                                      |
|-------------|-------------------------------------------------|
| `Tab`       | автодополнение команд и путей (жми постоянно!)  |
| `Tab Tab`   | показать все варианты                           |
| `↑ ↓`       | листать историю команд                          |
| `Ctrl+C`    | прервать текущую команду                        |
| `Ctrl+L`    | очистить экран                                  |
| `Ctrl+R`    | поиск по истории команд                         |
| `Ctrl+A` / `Ctrl+E` | в начало / в конец строки               |
| `Ctrl+D`    | выйти из терминала                              |

```bash
history         # список выполненных команд
```

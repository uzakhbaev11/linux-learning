# Модуль 1. Задания

Сначала подготовь файлы для заданий:

```bash
lab setup 1
```

Будет создана папка `~/m01`. Все ответы сохраняй туда.

---

## Задание 1. Познакомься с системой

Выполни по очереди и посмотри на результат:

```bash
pwd
whoami
hostname
date
uname -a
```

Теперь сохрани результаты в файлы:
- имя пользователя → в файл `~/m01/me.txt`
- информацию о системе (`uname -a`) → в файл `~/m01/system.txt`

💡 Нужен символ `>` из теории.

## Задание 2. Найди тайную комнату

В папке `~/m01/house` есть «дом» с комнатами. Одна комната **спрятана**.
В ней лежит записка с секретным словом.

1. Перейди в `~/m01/house`.
2. Посмотри, какие комнаты видны обычным `ls`.
3. Найди спрятанную комнату.
4. Зайди в неё и прочитай записку.
5. Сохрани **только секретное слово** в файл `~/m01/code.txt`.

💡 `echo слово > файл` записывает текст в файл.

## Задание 3. Путешествие по системе

1. Перейди в папку `/etc`. Здесь хранятся настройки системы.
2. Находясь в `/etc`, сохрани список её файлов в `~/m01/etc-list.txt`.
3. Вернись в предыдущую папку одной короткой командой.
4. Поднимись на уровень выше с помощью `..` и проверь через `pwd`, где ты.
5. Вернись домой самым коротким способом.

## Задание 4. Научись искать ответы сам

> Проверяется вопросами в квизе.

Не гугли, используй `man ls`:
1. Найди флаг `ls`, который сортирует файлы **по размеру**.
2. Найди флаг, который показывает размеры в «человеческом» виде (K, M, G).
3. Выполни `ls -la /etc` и `ls -lhS /etc`. Чем отличаются результаты?

💡 Внутри `man` ищи через `/size`, а `n` переходит к следующему совпадению.

## Задание 5. Горячие клавиши

> Проверяется вопросами в квизе.

Потренируйся:
1. Набери `ls /e`, нажми `Tab`. Путь дополнился?
2. Запусти `sleep 100` (команда просто ждёт 100 секунд) и прерви её через `Ctrl+C`.
3. Нажми `Ctrl+R` и набери `uname`: ты найдёшь команду из истории.
4. Очисти экран через `Ctrl+L`.

## Задание 6. История команд

Сохрани историю своих команд в файл `~/m01/history.txt`.

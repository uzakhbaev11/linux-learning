# Модуль 2. Задания

```bash
lab setup 2
```

Будет создана папка `~/m02` с материалами для заданий.

---

## Задание 1. Экскурсия по системе

Загляни в каждую из папок: `/etc`, `/var/log`, `/usr/bin`, `/tmp`, `/home`, `/root`.

- В `/usr/bin` найди программы, которыми ты уже пользовался (`ls`, `pwd`...).
- Что случится при попытке зайти в `/root`? Почему так?
- Найди в `/etc` файл с именем компьютера и выведи его через `cat`.

## Задание 2. Структура проекта

Создай структуру будущего бэкенд-проекта **как можно меньшим числом команд**:

```
~/m02/myapp/
├── README.md
├── config/
├── docs/
├── src/
│   └── main.py
└── tests/
```

💡 `mkdir -p` и фигурные скобки `{}` помогут сделать это за 2 команды.

## Задание 3. Разбери «Загрузки»

В `~/m02/downloads` лежит куча файлов вперемешку.

1. Создай внутри три папки: `images`, `documents`, `music`.
2. Перемести:
   - `.jpg` и `.png` → `images`
   - `.pdf` и `.txt` → `documents`
   - `.mp3` → `music`
3. Удали все `.tmp` файлы.

В итоге в корне `downloads` должны остаться только три папки.
💡 Используй шаблоны `*`. Не перемещай файлы по одному!

## Задание 4. Сокровище в лабиринте

Где-то в `~/m02/maze` спрятан файл `treasure.txt`.

1. Найди его с помощью `find`.
2. Создай папку `~/m02/found` и **скопируй** (не перемести!) туда сокровище.
3. Прочитай, что в нём написано.

## Задание 5. Что занимает место?

В лабиринте есть один файл размером **больше 1 МБ**. Найди его через `find`
и запиши его **абсолютный путь** в файл `~/m02/big.txt`.

💡 `realpath` превращает относительный путь в абсолютный.

## Задание 6. Бэкап и переименование

1. Сделай резервную копию всей папки `~/m02/myapp` → `~/m02/myapp-backup`.
2. В `~/m02/myapp` переименуй папку `docs` в `documentation`.

## Задание 7. Уборка

Удали папку `~/m02/trash` целиком, со всем содержимым.
Сначала посмотри, что внутри (`tree ~/m02/trash`), и только потом удаляй.

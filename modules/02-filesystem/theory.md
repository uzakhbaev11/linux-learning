# Модуль 2. Файловая система

> ⏱ ~2 занятия по часу

## Всё — это файл

В Linux нет дисков `C:` и `D:`, как в Windows. Есть **одно дерево**, которое начинается с корня `/`.
Всё, что есть в системе, — это файлы в этом дереве: документы, программы, настройки, диски, даже процессы.

## Главные папки (их нужно знать наизусть)

```
/
├── home/        домашние папки пользователей (/home/student)
├── root/        домашняя папка суперпользователя root
├── etc/         НАСТРОЙКИ системы и программ (nginx, ssh, пользователи)
├── var/         изменяемые данные
│   ├── log/     ЛОГИ — сюда смотришь, когда что-то сломалось
│   └── www/     часто здесь лежат сайты
├── tmp/         временные файлы (очищается при перезагрузке)
├── usr/         установленные программы
│   ├── bin/     исполняемые файлы программ (ls, grep, python3...)
│   └── local/   программы, установленные вручную
├── bin/         базовые команды (сейчас это ссылка на /usr/bin)
├── opt/         сторонние приложения (иногда сюда деплоят)
├── dev/         устройства (диски, терминалы)
└── proc/        информация о процессах и ядре (виртуальная)
```

Для бэкендера/DevOps самые важные:
- `/etc` — конфиги (например, `/etc/nginx/nginx.conf`, `/etc/ssh/sshd_config`)
- `/var/log` — логи
- `/home/<user>` — твои файлы и часто код приложения
- `/tmp` — временное

## Абсолютные и относительные пути

- **Абсолютный** путь начинается с `/` и работает откуда угодно: `/home/student/m02/notes.txt`
- **Относительный** путь считается от текущей папки: `m02/notes.txt`, `../etc`, `./script.sh`

```bash
cd /home/student     # абсолютный
cd m02               # относительный: /home/student/m02
cd ../..             # относительный: на два уровня вверх → /home
```

## Создание

```bash
mkdir projects                # создать папку
mkdir -p a/b/c                # создать всю цепочку папок сразу
touch file.txt                # создать пустой файл (или обновить дату изменения)
mkdir -p app/{src,tests,docs} # фигурные скобки: три папки одной командой
touch {a,b,c}.txt             # a.txt b.txt c.txt
```

## Копирование, перемещение, переименование

```bash
cp file.txt copy.txt          # копировать файл
cp file.txt dir/              # копировать в папку
cp -r dir1 dir2               # копировать ПАПКУ (-r = рекурсивно, со всем содержимым)
mv old.txt new.txt            # ПЕРЕИМЕНОВАТЬ (в Linux нет отдельной команды rename)
mv file.txt dir/              # переместить в папку
cp -i / mv -i                 # спросить перед перезаписью
```

## Удаление ⚠️

```bash
rm file.txt                   # удалить файл
rm -r dir                     # удалить папку со всем содержимым
rm -i file.txt                # спросить подтверждение
rmdir dir                     # удалить ПУСТУЮ папку
```

> 🚨 **В Linux нет корзины.** `rm` удаляет навсегда.
> Команда `rm -rf /` (или `rm -rf ~`) уничтожит систему (или твои файлы).
> Перед `rm -rf` всегда перечитай команду. На продакшен-сервере особенно.

## Шаблоны (wildcards)

Shell сам подставляет подходящие имена файлов:

| Шаблон | Значит                       | Пример                          |
|--------|------------------------------|---------------------------------|
| `*`    | любые символы (сколько угодно) | `*.jpg` — все jpg-файлы       |
| `?`    | ровно один любой символ      | `photo_?.jpg` — photo_1.jpg ... |
| `[ ]`  | один символ из набора        | `file[123].txt`                 |

```bash
ls *.txt              # все .txt
mv *.jpg images/      # переместить все jpg в папку images
rm *.tmp              # удалить все .tmp
```

💡 Перед `rm *.что-то` сначала выполни `ls *.что-то` и убедись, что удалится именно то, что нужно.

## Информация о файлах

```bash
tree                  # дерево папок
tree -a               # вместе со скрытыми
file photo.jpg        # тип файла (по содержимому, а не по расширению)
stat file.txt         # подробности: размер, права, даты
du -sh dir            # сколько места занимает папка
df -h                 # сколько места на дисках
realpath file.txt     # полный абсолютный путь к файлу
```

## Поиск: `find`

Это одна из самых полезных команд. Ищет файлы по имени, типу, размеру и дате.

```bash
find . -name "*.log"              # все .log в текущей папке и глубже
find /etc -name "*.conf"          # все .conf в /etc
find . -type d                    # только папки (d = directory)
find . -type f                    # только файлы (f = file)
find . -iname "readme*"           # без учёта регистра
find . -size +1M                  # файлы больше 1 мегабайта
find /var/log -mtime -1           # изменённые за последние сутки
find . -name "*.tmp" -delete      # найти и удалить
```

Реальный пример из DevOps: «на сервере кончилось место — найди, что занимает больше 100 МБ»:

```bash
sudo find / -type f -size +100M 2>/dev/null
```

(`2>/dev/null` прячет ошибки «нет доступа». Подробнее — в модуле 4.)

# Модуль 3. Задания

```bash
lab setup 3
```

В `~/m03` появятся: лог приложения `app.log`, конфиг `config.ini` и генератор живых логов `generator.sh`.

Ты играешь роль бэкендера, у которого «что-то сломалось на проде». Разберись по логам.

---

## Задание 1. Осмотрись

1. Сколько строк в `app.log`? (`wc -l`)
2. Открой лог через `less`. Найди внутри первое упоминание `Payment` (через `/`). Выйди.
3. Сохрани **первые 10 строк** лога в `~/m03/first10.txt`.
4. Сохрани **последние 3 строки** лога в `~/m03/last3.txt`.

## Задание 2. Ищем ошибки

1. Посчитай, сколько строк с `ERROR`, и запиши **только число** в `~/m03/errors_count.txt`.
2. Сохрани все строки с `ERROR` **вместе с номерами строк** в `~/m03/errors.txt`.
3. Пользователь с `user_id=1337` жалуется на проблемы. Сохрани все строки, где он упоминается, в `~/m03/user1337.txt`.
4. Сохрани все строки, где **нет** `INFO`, в `~/m03/not_info.txt`.

💡 Все эти задачи решаются одной командой `grep` с нужным флагом и `>`.

## Задание 3. Правим конфиг в nano

Открой `~/m03/config.ini` в **nano** и поменяй:
- `port=8080` → `port=3000`
- `debug=true` → `debug=false`

Сохрани и выйди. Остальные строки не трогай.

## Задание 4. Выйти из vim 😄

1. Открой `vim ~/m03/vim.txt` (файла пока нет, vim его создаст).
2. Перейди в режим вставки и напиши ровно одну строку: `I can exit vim`
3. Сохрани и выйди.
4. Ещё раз открой файл, удали строку через `dd` и выйди **без сохранения**.
   Проверь через `cat`, что строка осталась на месте.

## Задание 5. Живые логи (tail -f)

Генератор каждую секунду дописывает строку в `~/m03/live.log`, как настоящее приложение пишет свой лог.

1. Запусти генератор **в фоне**: `bash ~/m03/generator.sh &`
   Значок `&` в конце запускает программу в фоне, и терминал остаётся свободным. Подробно разберём в модуле 6.
2. Сразу начни следить за логом: `tail -f ~/m03/live.log`
3. Примерно через 25 секунд в логе появится секретное слово (`SECRET=...`). Запомни его, оно понадобится в квизе.
4. Останови `tail` через `Ctrl+C`.

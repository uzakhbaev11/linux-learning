# 🐧 Linux с нуля: для бэкендера с прицелом на DevOps

Практический курс-лаборатория. Ты не только читаешь, но и работаешь в настоящем Linux (Ubuntu 24.04 в Docker),
выполняешь задания, а скрипты проверяют, всё ли получилось.

**Цель:** через ~2 месяца уверенно работать на Linux-сервере: найти проблему в логах,
настроить права и сервисы, написать bash-скрипт и **самому задеплоить свой бэкенд** на сервер.

## 🚀 Быстрый старт (Docker-лаборатория на своём компьютере)

1. Запусти **Docker Desktop** на Mac.
2. В терминале Mac:
   ```bash
   cd ~/Desktop/my-projects/linux-learning
   ./lab/start.sh
   ```
   Первый запуск займёт несколько минут: собирается учебный Linux.
3. Ты внутри Linux! Приглашение выглядит так: `student@linux-lab:~$`
4. Дальше:
   ```bash
   lab help        # список команд курса
   lab theory 1    # теория модуля 1
   lab setup 1     # подготовить задания
   lab tasks 1     # открыть задания
   lab check 1     # проверить себя
   ```
5. Выйти из Linux: `exit` или `Ctrl+D`. Твои файлы сохранятся до следующего `./lab/start.sh`.

> 💡 Теорию и задания удобнее читать в редакторе на Mac (VS Code и т.п.), а команды выполнять в терминале Linux.

| Команда на Mac              | Что делает                                  |
|-----------------------------|---------------------------------------------|
| `./lab/start.sh`            | войти в учебный Linux                       |
| `./lab/reset.sh`            | сбросить Linux в чистое состояние           |
| `./lab/reset.sh --rebuild`  | сброс + пересборка образа                   |

Пароль пользователя `student` (для `sudo`): **student**

## 📅 Как заниматься (1 час в день)

| Время    | Что делать                                                         |
|----------|--------------------------------------------------------------------|
| 10 мин   | Теория (`theory.md`): прочитай и попробуй примеры руками          |
| 40 мин   | Задания (`tasks.md`), потом `lab check N`                          |
| 10 мин   | Запиши новые команды **своими словами** в `cheatsheet.md`          |

Правила:
- **Набирай команды руками**, не копируй. Так работает мышечная память.
- Застрял больше чем на 15 минут? Посмотри `man`, потом подсказку в проверке, и только потом спрашивай.
- Каждый модуль занимает 1–3 занятия. Это нормально.
- Сломал систему? Отлично, ты чему-то научился. `./lab/reset.sh` вернёт всё назад.

| #  | Модуль                        | Что освоишь                                         | Статус |

# 🏁 Итоговый проект: свой сервер с бэкендом

Цель: взять **чистый Linux-сервер** и самостоятельно, только через терминал, развернуть на нём
бэкенд-приложение так, как это делают в реальных компаниях.

Подойдёт любое твоё приложение, например один из твоих ботов (`queue-bot`, `platonus-grades-bot`)
или простой API.

## Что нужно сделать

1. **Сервер.** Поднять VM (Multipass/UTM) или арендовать дешёвый VPS.
2. **Безопасность**
   - создать отдельного пользователя с `sudo`, не работать под root
   - вход по SSH-ключу, вход по паролю и вход под root отключить
   - firewall (`ufw`): открыть только 22, 80, 443
3. **Окружение**
   - установить нужный язык и зависимости через `apt`
   - секреты хранить в `.env` с правами `600`
4. **Приложение как сервис**
   - unit-файл systemd: автозапуск, перезапуск при падении
   - логи смотреть через `journalctl`
5. **Nginx** как reverse proxy перед приложением
6. **Автоматизация**
   - bash-скрипт деплоя (`git pull` → установка зависимостей → перезапуск сервиса)
   - cron-бэкап (база или данные) с ротацией старых архивов
7. **Документация:** README с описанием, как всё устроено и как восстановить сервер с нуля

## Критерий готовности

Приложение работает, переживает перезагрузку сервера, сам сервер защищён,
и ты можешь объяснить каждую строчку конфигурации.

> Детальное пошаговое ТЗ появится, когда ты пройдёшь модули 1–12.
